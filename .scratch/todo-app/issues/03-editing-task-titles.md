# 03: Editing task titles

**What to build:** A user can edit an existing task's title inline and keep the change after reloading the app.

**Blocked by:** 01: Persisting and creating tasks.

**Status:** ready-for-agent

- [ ] A task title can be edited inline and saved.
- [ ] Leading and trailing whitespace is removed from edited titles.
- [ ] A blank or whitespace-only edit is rejected without replacing the existing title.
