# 02: Completing and deleting tasks

**What to build:** A user can mark a task complete or active, see active and completed tasks in separate sections on the same screen, and permanently delete a task.

**Blocked by:** 01: Persisting and creating tasks.

**Status:** ready-for-agent

- [ ] A task can be marked complete and returned to active; the status remains correct after reloading the app.
- [ ] Active and completed tasks appear in separate sections on the same screen.
- [ ] A task can be permanently deleted and does not reappear after reloading the app.
