# Todo App

This glossary defines the language for the single-user task list managed by the app.

## Language

**할 일**:
An individual item the user intends to complete. Each item is distinct even when titles match, and it remains an item whether active or complete.
_Avoid_: "할 일 목록" when referring to one item

**완료**:
A reversible state indicating that a 할 일 has been done; it does not mean the item was deleted.
_Avoid_: 삭제
